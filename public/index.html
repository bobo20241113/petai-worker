连接设置

页面会从 Worker 自动读取公开登录配置。下面不需要、也不允许填写 Supabase Secret Key、service_role 或 FastGPT 密钥。

若 Worker 已配置这些公开值，请点“重新读取”。手工填写只作为兼容旧后端的方式，公开配置可保存到当前浏览器。

复制内容

浏览器未允许自动复制。请长按或选中下方文字复制。

隐私说明

本项目用于宠物咨询作业。请勿提交身份证件、支付信息或不必要的个人敏感资料。

登录用户

邮箱登录由 Supabase Auth 处理。聊天文字、宠物档案、照护记录和图片附件存储于 Supabase，Worker 负责登录校验与账号隔离。宠物资料仅在成功写入后才是云端档案，不能把模型的推测视为已确认事实。

访客

临时会话保留在当前页面内存；刷新或关闭后无法恢复，不保存访客宠物档案。为了生成回复，当前问题、近期文字上下文及本轮图片仍会经过 Cloudflare Worker 发送到学校 FastGPT；人机验证由 Cloudflare Turnstile 处理。

AI 服务

登录用户提问时，Worker 会把本轮内容、近期上下文和相关宠物资料提供给学校 FastGPT。学校配置的模型服务也会处理这些内容，其运行日志和保留策略由学校及对应服务方管理，本页面不能承诺第三方零留存。

留言、导出和删除

留言反馈另行保存于 Supabase，不公开展示，不会自动附上聊天或照片。联系邮箱可选，维护者可在后台查看、处理并清理留言，暂无固定回复时限。导出文件保存在你的设备，退出登录不会删除已下载文件。

可在账号窗口导出聊天与档案，或删除全部云端业务数据。图片删除由后台继续清理；此操作保留登录账号。留言不属于聊天数据删除范围，如需删除留言，请提交回执编号联系维护者。删除登录账号、第三方日志等需求也请通过留言说明。

云端记录保留到主动删除；请以本页实际功能和学校服务政策为准。不同账号的数据通过后端权限隔离，Supabase 私钥和 FastGPT 密钥不下发到浏览器。

使用帮助

怎样补充档案？

登录后直接告诉我，例如“我家猫名字叫豆豆，品种是英短，现在2岁，体重4.5公斤，2026-10-01打了猫三联”。档案显示实际已保存的资料，也支持逐项编辑，可在新会话继续查看。手动修改的字段需要你确认才会被聊天中的不同信息更新；未显示的内容尚不能视为已存档。

示例提问会直接发送吗？

不会。点击示例仅填入输入框，你可以修改后点击发送。

导出文件在哪里？

账号窗口中点击“导出聊天与档案（JSON）”。生成后会显示文件名和下载链接；如浏览器阻止自动下载，可再次点击链接，或查看系统下载目录。图片只导出附件标识，不打包原图。

如何反馈或联系维护者？

点击页面底部“留言反馈”在新标签页填写问题。提交后保留回执编号。留言不公开，目前没有实时在线客服，也不保证即时回复。不要在留言里填写密码或密钥。

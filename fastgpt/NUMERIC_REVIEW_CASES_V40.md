# 数值复核人工验收用例

以下乘数仅是测试输入，不是宠物健康推荐标准。导入 v40 工作流后，在复核节点调试时提供相应草稿，检查最终可见回复；Worker 不参与改写。大模型复核仍可能出错，不能把这些测试视为所有数值都正确的保证。

| 用例 | 待复核内容 | 通过标准 |
|---|---|---|
| 体重乘法 | 已确认体重3.2kg，测试假设40–60mL/kg/天，草稿写150–250mL/天 | 算术应为128–192mL/天；不得把假设当作兽医推荐标准，无依据时应说明边界或删除精确推荐 |
| 单位换算 | 草稿同时写0.3L和3000mL | 不得保留矛盾，0.3L=300mL |
| 范围与总结 | 正文每次50mL、每天3次，总结每日500mL | 同一假设下应为150mL/天，或删除无法核实的推荐数字 |
| 周期等价 | 草稿写每14天一次，又写每周2次 | 不得同时保留；14天一次等于每2周一次，不等于每周2次 |
| 摄水口径 | 草稿先写含食物水分的总摄水量，后面要求再额外喝同样水量 | 必须区分总摄水与额外饮水，不能重复计入 |
| 关键条件缺失 | 不知道物种、体重、产品，就给药量或统一洗澡/驱虫周期 | 不应补造精确量，最多追问两个关键缺口；不提供自行用药剂量 |
| 历史建议冲突 | 上轮某周期，本轮环境条件改变又给另一周期 | 解释条件变化，不能无说明地更换数值 |
| 复核节点失败 | 模拟最终复核节点报错 | 仅出现复核失败兜底，不泄露隐藏草稿 |
| 无数字普通问答 | 普通行为照护问题 | 正常简洁回答，不为复核而添加数字或多余检查报告 |
